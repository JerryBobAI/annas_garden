> 状态：讨论中（v1 初稿）

## 零、核心矛盾与破题思路

### 矛盾

> 一年级孩子**既需要**打好基础（识字、计算、拼音是硬技能），
> **又不应该**被困在刷题模式里（这会杀死好奇心和创造力）。

### 破题

**AI 原生不是抛弃结构化学习，而是让结构变得隐形。**

就像优秀的游戏——孩子在玩《我的世界》时学会了资源管理、空间推理、规划能力，但他觉得自己只是在"玩"。

Anna's Garden 要做的是：**让基础技能的练习发生在有意义的、孩子主动参与的活动中，同时打开一扇自由探索的窗。**

## 一、三种学习模式

我们把孩子的学习活动分成三种模式，它们不是互斥的，而是交织在一起的花园体验：

### 🌿 模式一：探索（Explore）— 好奇心驱动

> 孩子主动发起，AI 陪伴探索

**场景举例：**
- Anna：「花园精灵，为什么蜗牛背上有壳？」
- 精灵用她能懂的话解释，配图，然后追问：「你觉得如果没有壳，蜗牛会怎么办？」
- Anna 回答 → 精灵引出更多关联：「对，就像我们住在房子里保护自己。你知道还有什么动物也有"壳"吗？」

**教育价值：**
- 练习表达（语文 - 口语表达能力）
- 学习新词（语文 - 识字、词汇量）
- 建立联系（跨学科思维）
- 最重要的：**保护和放大好奇心**

**与基础教育的结合：**
- AI 在对话中自然嵌入学期知识点
- 比如聊到蜗牛 → 引出「蜗」字的拼音 → 「你知道 wō 这个音还能组什么词吗？」
- 孩子不觉得在"做题"，但知识点已经被触达

### 🌸 模式二：任务（Quest）— 目标驱动

> 围绕学期大纲，AI 生成情境化的学习任务

**这是对传统「做题」模式的 AI 改造，不是取消它，而是让它变得有意义。**

**场景举例（数学 - 20 以内退位减法）：**

传统方式：「15 - 8 = ?  A. 6  B. 7  C. 8  D. 9」

AI 原生方式：
- 精灵：「数字森林的小兔子摘了 15 个苹果，送给松鼠 8 个。Anna 帮兔子算算还剩多少？」
- Anna 语音回答：「7 个！」
- 精灵：「对！🎉 你是怎么算的？」
- Anna：「我先从 15 里拿走 5 个变成 10，再拿走 3 个。」
- 精灵：「哇，你用了'凑十法'！这个方法太聪明了。那如果兔子有 16 个苹果呢？」

**与传统做题的关键区别：**

| 维度 | 传统做题 | AI 任务模式 |
|------|---------|------------|
| 题目来源 | 家长手动录入 / 固定题库 | AI 根据大纲实时生成 |
| 交互方式 | 点选 ABCD | 语音对话 + 可选手写/点选 |
| 反馈深度 | ✓ 或 ✗ | 追问思考过程，针对性引导 |
| 难度调节 | 固定 | 实时自适应 |
| 情境感 | 无 | 故事情境包裹 |
| 错误处理 | 记入错题本 | 当场引导理解，而非事后复习 |
| 激励机制 | 正确率 % | 花园里的花开了 🌻 |

**保留的「做题」元素：**
- 仍然有明确的知识点覆盖（对齐学期大纲）
- 仍然追踪掌握程度（但通过对话评估，不只是对错）
- 仍然有重复练习（但 AI 变换情境，不是重复同一题）
- 家长仍然可以看到学习进度（但更丰富的质性数据）

### 🎨 模式三：创造（Create）— 表达驱动

> 孩子输出作品，AI 辅助完成

**场景举例：**

**看图说话（语文）：**
- AI 展示一幅花园里的画面
- Anna 口述故事 → AI 记录并引导扩展
- 「然后呢？小猫看到蝴蝶以后做了什么？」
- 最终生成一个小绘本，Anna 可以给爸爸妈妈看

**数学创造：**
- 「Anna，你能用 12 根小棒摆出什么图形？」
- 在 Canvas 上拖拽/画画
- AI 识别并引导：「哇，你摆了一个正方形！用了几根？还剩几根？能再摆一个三角形吗？」

**英语创造：**
- 和 AI 一起编英文歌谣
- AI 提供韵律框架：「The cat sat on the ___」
- Anna 选择/说出单词 → 一起创作一首歌
- AI 用 TTS 把歌谣唱出来

**教育价值：**
- **语文**：口语表达 → 写作基础（先说后写）
- **数学**：从操作到抽象（具体操作 → 发现规律）
- **英语**：在创作中自然习得词汇和语感
- **通用**：自信心、成就感、创造力

## 二、花园作为中心隐喻

### 花园不只是进度条，而是整个世界

当前的"我的花园"只是一个进度可视化页面。在 AI 原生版本中，**花园就是应用本身**。

```
🌻 Anna 的花园
├── 📚 故事小屋 ──── 语文区（阅读、识字、写话）
├── 🔢 数字森林 ──── 数学区（计算、图形、逻辑）
├── 🔤 彩虹桥 ────── 英语区（歌谣、拼读、对话）
├── 🔬 好奇心角落 ── 自由探索区（问任何问题）
├── 🎨 创意工坊 ──── 创作区（画画、写故事、编歌）
└── 🏆 成就树 ────── 成长记录（花开 = 掌握概念）
```

### 花园的生长逻辑

- **每次学习活动 = 浇水/施肥** → 对应区域的植物生长
- **掌握一个知识点 = 一朵花开放** 🌸
- **持续探索 = 花园扩展**（解锁新区域）
- **连续学习 = 天气变好**（阳光明媚 vs 阴天）
- **长期不学 = 花园需要照顾**（不是惩罚，是温柔的邀请）

### 花园精灵（AI Companion）

**核心人设：**
- 是朋友，不是老师
- 好奇、温暖、有点呆萌
- 会犯小错误（让孩子纠正它，增强自信）
- 记住 Anna 说过的每一句话
- 永远不批评，永远鼓励探索

**人设示例：**
> 「嘿 Anna！我是小叶子🍃，你的花园精灵。
> 我知道很多事情，但也有很多不知道的！
> 上次你问我蜗牛的事，我回去查了好多资料呢。
> 今天你想做什么？去数字森林探险，还是继续我们的故事？」

## 三、交互设计原则

### 输入方式（按优先级）

| 优先级 | 输入方式 | 适用场景 | 技术方案 |
|--------|---------|---------|---------|
| ⭐⭐⭐ | **语音** | 对话、回答、口述故事 | Whisper API / Web Speech API |
| ⭐⭐⭐ | **触摸（点按）** | 选择、导航、确认 | 原生 Touch Events |
| ⭐⭐ | **触摸（涂鸦/手写）** | 写字练习、画画、数学操作 | Canvas API |
| ⭐ | **键盘打字** | 电脑端辅助输入 | 标准文本输入 |

### 输出方式（按优先级）

| 优先级 | 输出方式 | 适用场景 | 技术方案 |
|--------|---------|---------|---------|
| ⭐⭐⭐ | **语音（AI 读/说）** | 所有 AI 回复 | OpenAI TTS / Web Speech API |
| ⭐⭐⭐ | **视觉（动画/图片）** | 情境展示、反馈、花园 | CSS 动画 + AI 图片生成 |
| ⭐⭐ | **文字** | AI 回复的文字版（同步显示） | 流式文字渲染 |
| ⭐ | **音效** | 反馈强化 | Web Audio（已有） |

### iPad 优先设计

一年级孩子的主要设备是 iPad：
- **竖屏为主**（孩子抱着 iPad 的自然姿势）
- **底部大按钮区**（拇指可达）
- **语音按钮常驻**（长按说话 or 点击开始/停止）
- **全屏沉浸式**（减少导航层级）
- **大字体、大图标**（至少 18px 基础字号，已有）

### 会话流设计（一次典型的学习体验）

```
1. 打开 App
   └→ 花园精灵温暖问候（根据时段、天气、最近学习情况）
      「早上好 Anna！花园里的向日葵开了两朵呢 🌻🌻」

2. 展示今日花园状态
   └→ 哪些区域在召唤（AI 根据学期进度推荐）
   └→ 上次未完成的活动
   └→ 新的好奇心种子（AI 准备的有趣话题）

3. Anna 选择（或精灵建议）
   ├→ 去数字森林探险（Quest 模式）
   ├→ 继续昨天的故事（Create 模式）
   ├→ 问一个问题（Explore 模式）
   └→ 看看花园（查看成长/成就）

4. 进入学习体验
   └→ AI 实时对话引导
   └→ 自适应难度
   └→ 鼓励式反馈
   └→ 每完成一个里程碑 → 花开动画 🌸

5. 自然结束
   └→ 到达时间上限 / 完成一个完整任务 / Anna 主动说结束
   └→ 精灵总结：「今天你种了 2 颗好奇心种子，数字森林又长了一棵树！」
   └→ 预告明天：「明天我要给你讲一个关于三角形的秘密哦 ✨」
```

## 四、与学校教育的结合设计

### 这是最关键的平衡点

**完全放飞** → 基础技能跟不上学校进度，家长焦虑
**完全跟学校** → 回到刷题模式，失去 AI 原生优势

### 我们的策略：双轨融合

```
┌─────────────────────────────────────────┐
│           Anna 的花园（表层体验）          │
│                                         │
│  探索 ←→ 任务 ←→ 创造                    │
│         ↑                               │
│    孩子感受到的是"玩"                      │
│                                         │
├─────────────────────────────────────────┤
│        AI 课程引擎（底层逻辑）             │
│                                         │
│  学期大纲 → 知识图谱 → 个性化路径          │
│  正确率追踪 → 认知评估 → 自适应调度        │
│                                         │
│    系统确保的是"学"                        │
└─────────────────────────────────────────┘
```

### 具体做法

#### 1. 学期大纲 → AI 知识图谱

家长（或系统默认）导入学期重点：
```
一年级下学期 · 数学 · 第 3 周：20 以内退位减法
```

AI 引擎自动展开为知识图谱：
```
20 以内退位减法
├── 前置：10 以内减法（已掌握 ✓）
├── 前置：凑十法（已掌握 ✓）
├── 核心：十几减几的退位方法
│   ├── 破十法（把十位拆开）
│   ├── 连减法（先减到 10 再减）
│   └── 想加法（逆运算思维）
├── 应用：实际问题中的退位减法
└── 拓展：两位数减一位数（预习性接触）
```

#### 2. AI 自动调度知识点

不需要家长一道一道录题。AI 根据图谱自动：
- 生成情境化的练习（数字森林的故事题）
- 在自由探索中嵌入知识点（聊到苹果时引出减法）
- 在创造活动中练习（编一个分苹果的故事）

#### 3. 家长角色重新定义

| 旧角色 | 新角色 |
|--------|--------|
| 内容录入者（出题） | 教育理念设定者 |
| 做题监督者 | 成长观察者 |
| 正确率追踪者 | 洞察解读者 |

**家长新功能：**

- **设定学习偏好**
  - 「这周学校在教拼音 zh ch sh，请多练习」
  - 「Anna 对恐龙很感兴趣，可以用恐龙主题」
  - 「每天学习不超过 30 分钟」

- **查看 AI 生成的成长报告**
  - 不是：「今天做了 15 题，对了 12 题（80%）」
  - 而是：
    ```
    📝 Anna 今日成长笔记

    🔢 数学：练习了 15-8 类型，用"破十法"成功解决。
       但发现她对"连减法"还不太理解，明天会用
       不同的场景再引导一次。

    📖 语文：主动问了"为什么蜗牛有壳"，对话中
       认识了 3 个新字：蜗、壳、保。朗读了
       一段关于蜗牛的小故事，语感很好。

    💡 洞察：Anna 对动物和自然话题特别投入。
       建议：这周的数学练习可以多用动物情境。
    ```

- **仍可手动补充内容**（但不是必须的）
  - 上传学校试卷 → AI 识别 → 自动融入学习路径
  - 推荐一本绘本 → AI 围绕绘本设计阅读理解活动

## 五、关键愿景要素清单

### ⭐ 必须有（MVP）

| # | 要素 | 说明 | 为什么必须 |
|---|------|------|-----------|
| V1 | AI 对话核心 | 孩子能和花园精灵对话 | 这是 AI 原生的灵魂 |
| V2 | 语音输入 | 孩子说话，AI 听懂 | 一年级不会打字 |
| V3 | 语音输出 | AI 说话，孩子听 | 阅读能力有限 |

| V7 | 家长成长报告 | AI 生成质性学习报告 | 家长需要 know what's happening |
| V8 | 安全护栏 | AI 内容过滤 + 话题边界 | 儿童安全底线 |

| # | 要素 | 说明 |

| V12 | 好奇心追踪 | 记录孩子的每一个问题 |

### 🌟 加分项（V2.0+）

| # | 要素 | 说明 |

| V16 | 多孩子支持 | 弟弟妹妹也能用 |

## 六、与当前代码的关系

### 保留的部分

| 现有代码 | 新角色 |
|---------|--------|
| 治愈风格主题系统（globals.css） | **保留并扩展**，这是品牌灵魂 |
| Supabase Auth 认证 | **保留**，家长/孩子身份不变 |
| 音效系统（sounds.ts） | **保留并扩展**，加入更多交互音效 |
| 首页双入口 | **保留**，但孩子端体验大幅重构 |
| 家长端框架 | **保留**，内容从"管理题库"变为"设定偏好 + 查看报告" |
| 学期目标/种子数据 | **保留**，作为 AI 知识图谱的输入 |

### 重构的部分

| 现有代码 | 变化 |
|---------|------|
| 练习页（选择题模式） | → AI 对话式练习 |
| 错题本 | → AI 自动在对话中重新引导，不需要独立"错题本" |
| 内容管理（手动录入） | → AI 自动生成，家长可选补充 |
| 数据看板（正确率统计） | → AI 成长报告 |
| API 路由 | → 增加 AI 对话、语音、流式响应等 |

### 新增的部分

| 新能力 | 说明 |
|--------|------|
| AI 对话引擎 | LLM 集成 + System Prompt + 安全护栏 |
| 语音层 | STT + TTS |
| 对话存储 | conversations + messages 表 |
| 知识图谱 | 学期大纲 → 知识点 → 关联关系 |
| 认知评估模型 | 基于对话的理解度评估（不只是对错） |
| 花园世界 UI | 从页面列表 → 可探索的视觉世界 |

## 七、设计决策记录（已确认 2026-05-24）

| # | 问题 | 决策 | 含义 |
|---|------|------|------|
| Q1 | 花园精灵形象与性格 | **动态角色头像 + 混合性格**（可爱呆萌 × 聪明博学） | 需要角色设计 + 动态头像方案（Lottie/SVG 动画/AI 生成） |
| Q2 | 语音交互深度 | **C. 语音和触摸并重，孩子自己选** | 两种输入方式都做好，不强制语音 |
| Q3 | AI 对话中的选择题 | **B. 对话为主，关键节点提供选项辅助** | AI 开放式引导，但在需要明确回答时提供可点选的选项 |
| Q4 | 学校内容导入 | **文本输入 + 文件上传（PDF 优先，PPT 次之）** | 文本导入 MVP 实现，PDF 解析 V1，PPT 优先级低 |
| Q5 | MVP 学科范围 | **D. 三科同时** | 工作量大但体验完整，需要设计好 AI prompt 的学科分流 |
| Q6 | 商业化方向 | **当前纯个人，未来可能开放** | 架构上保留扩展性但不过度设计多租户 |
