# gstack — AI-Powered Development Toolkit

List and invoke any of the following gstack skills. Ask the user which one they want to run.

## Available Skills

### 🧠 Planning & Strategy
- `/office-hours` — YC-style brainstorming and idea validation
- `/plan-ceo-review` — CEO/founder-mode plan review (think bigger)
- `/plan-eng-review` — Engineering architecture review (lock the plan)
- `/plan-design-review` — Designer's eye plan review (before implementation)
- `/plan-devex-review` — Developer experience plan review (APIs, CLIs, SDKs)
- `/autoplan` — Run all reviews automatically in sequence

### 🎨 Design
- `/design-consultation` — Create a design system and DESIGN.md
- `/design-shotgun` — Generate multiple design variants for comparison
- `/design-html` — Turn approved designs into production HTML/CSS
- `/design-review` — Visual QA: find and fix design inconsistencies

### 🔍 Code Quality
- `/review` — Pre-landing PR code review
- `/qa` — Systematically test and fix bugs in a web app
- `/qa-only` — Report-only QA testing (no fixes)
- `/health` — Code quality dashboard with composite score
- `/investigate` — Systematic root cause debugging

### 🚀 Ship & Deploy
- `/ship` — Full ship workflow: test → review → version bump → PR
- `/land-and-deploy` — Merge PR, wait for CI, verify production
- `/canary` — Post-deploy canary monitoring
- `/setup-deploy` — Configure deployment settings
- `/document-release` — Post-ship documentation update

### 🌐 Browser & Testing
- `/browse` — Headless browser for QA and dogfooding
- `/setup-browser-cookies` — Import cookies for authenticated testing
- `/benchmark` — Performance regression detection
- `/devex-review` — Live developer experience audit

### 🔒 Security & Safety
- `/cso` — Security audit (OWASP + STRIDE + supply chain)
- `/careful` — Warn before destructive commands
- `/freeze` — Restrict edits to a specific directory
- `/guard` — Full safety mode (careful + freeze)
- `/unfreeze` — Remove edit restrictions

### 📦 Utilities
- `/retro` — Weekly engineering retrospective
- `/codex` — OpenAI Codex CLI: review, challenge, or consult
- `/learn` — Manage project learnings across sessions
- `/context-save` — Save working context for later
- `/context-restore` — Restore saved working context
- `/scrape` — Pull data from a web page
- `/gstack-upgrade` — Upgrade gstack to latest version
