---
description: Open a headless browser to test, QA, or dogfood a web page
---

Use the `skill` tool to invoke the `browse` skill from gstack.
This provides a fast headless browser for QA testing and site dogfooding.

Capabilities:
- Navigate any URL
- Interact with elements (click, type, scroll)
- Take annotated screenshots
- Check responsive layouts
- Test forms and uploads
- Handle dialogs
- Assert element states
- Diff before/after actions
