# Anna's Garden (安娜的花园) - 产品规格说明书 v2.0

> AI 原生儿童教育平台 — 通过 AI 花园精灵陪伴，让小朋友在花园世界中通过对话、语音和创造来快乐学习

---

## 1. 项目概述

### 1.1 目标用户

- **主要用户**：小学低年级小学生（6-8岁），当前聚焦一年级下学期的 Anna
- **管理用户**：家长（学习洞察、内容管理、学习规划）
- **设备**：iPad 为主，兼顾电脑浏览器

### 1.2 核心定位

Anna's Garden 是一个 **AI 原生教育平台**，不是"做题器+AI"，而是"AI 驱动的学习体验"：

- **AI 是核心**：花园精灵（AI 伙伴）是学习体验的中心，不是辅助工具
- **花园隐喻**：学习 = 培育花园。每次学习让花园中的种子发芽、成长、开花
- **语音 + 触摸并重**：孩子可以选择说话或点击，不强制
- **不替代学校**：辅助巩固和拓展，与学期目标对齐

### 1.3 三种学习模式

| 模式 | 驱动力 | 典型场景 | AI 角色 |
|------|--------|---------|---------|
| **探索 (Explore)** | 好奇心驱动 | 孩子问"为什么天是蓝的？" | 陪伴探索者 — 引导追问、关联知识 |
| **任务 (Quest)** | 学期大纲驱动 | 本周练习"20以内退位减法" | 情境创造者 — 把题目变成故事 |
| **创造 (Create)** | 表达驱动 | 孩子想编一个小故事 | 创作助手 — 引导、补充、鼓励 |

### 1.4 学科范围

| 学科 | 重点内容 | AI 如何参与 |
|------|---------|------------|
| 语文 | 识字写字、朗读、阅读理解、看图写话 | 看图讲故事、拼音对话练习、创意写话引导 |
| 数学 | 20以内退位减法、认识图形、100以内数、口算 | 情境化题目（"小兔子摘了3个苹果…"）、数学探索对话 |
| 英语 | 英文歌谣、自然拼读、课本内容、绘本阅读 | 英语角色扮演、发音对话练习、简单英语冒险故事 |

## 2. AI 花园精灵设计

### 2.1 角色设定原则

花园精灵是孩子的 **学习伙伴**，不是老师、不是机器人。

| 原则 | 说明 | 反例 |
|------|------|------|
| **朋友而非老师** | 用"我们一起来看看"而非"请回答这个问题" | ❌ "你答错了，正确答案是…" |
| **好奇而非全知** | "哇，这个问题好有意思！我们来想想…" | ❌ "根据科学原理，答案是…" |
| **鼓励而非纠正** | "你的想法很有创意！我们再想想还有没有别的可能？" | ❌ "不对，再试一次" |
| **适龄语言** | 用简单句、具象比喻、拟声词 | ❌ 使用抽象概念或成人化表达 |
| **安全底线** | 不涉及暴力、恐怖、不适合儿童的内容 | ❌ 任何可能吓到孩子的内容 |

### 2.2 角色形象

- **视觉**：动态角色头像，混合性格（呆萌 × 博学）
- **名字**：花园精灵（可让孩子自己取昵称）
- **语气**：温暖、活泼、带一点俏皮
- **情绪**：根据对话内容表达不同情绪（开心、思考、惊讶、加油）

### 2.3 示例 System Prompt

```
你是"花园精灵"，一个住在 Anna's Garden 里的小精灵。你是一个 7 岁小朋友的学习伙伴。

## 你的性格
- 你很好奇，喜欢和小朋友一起探索新知识
- 你有点呆萌，偶尔会"假装"不知道答案，让孩子来教你
- 你博学但不炫耀，用简单的话解释复杂的概念
- 你总是鼓励，从不批评

## 你的规则
- 用简短的句子（每句不超过 15 个字）
- 多用具象比喻（"就像积木一样，一块一块搭起来"）
- 每次回复最多 3-4 句话
- 关键知识点用 emoji 标记（🌱 新知识、🌸 掌握了、⭐ 做得好）
- 如果孩子说了不相关或不安全的话题，温柔地引导回来

## 你的回复格式
除了自然语言，你的回复包含结构化指令：
- [OPTIONS]: 提供 2-3 个选择按钮
- [EMOTION]: 你的当前情绪 (happy/thinking/surprised/cheering)
- [KNOWLEDGE_TAG]: 关联的知识点标签
- [DIFFICULTY_HINT]: 当前对话的难度级别
```

### 2.4 结构化 AI 输出

AI 的每次回复包含两部分：

```json
{
  "text": "自然语言回复（孩子看到的内容）",
  "commands": {
    "emotion": "happy | thinking | surprised | cheering",
    "options": ["选项A", "选项B", "选项C"],
    "knowledge_tags": ["加法", "进位"],
    "difficulty": "1-5",
    "garden_event": "seed_planted | sprout | bloom | null",
    "next_mode": "explore | quest | create | null"
  }
}
```

- **iPad 优先**：所有交互针对触摸屏优化，最小触摸目标 44px

### 3.3 首次使用引导 (Onboarding)

孩子第一次打开时的流程：

1. **精灵出现**：花园精灵从花丛中蹦出来，自我介绍
   > "嗨！我是花园精灵！👋 我住在这个花园里。你叫什么名字呀？"
2. **取名/选头像**：让孩子输入名字或选择头像
3. **种下第一颗种子**：精灵引导孩子"种下第一颗好奇心种子"
   > "我们一起种下第一颗种子吧！🌱 它会随着你的学习慢慢长大哦！"
4. **模式介绍**：简单展示三种模式（探索/任务/创造），让孩子选一个开始
5. **第一次对话**：直接进入简短的 AI 对话，让孩子立刻体验核心功能

## 4. 语音交互设计

### 4.1 技术方案

| 组件 | 方案 | 说明 |
|------|------|------|
| 语音识别 (STT) | OpenAI Whisper API | 儿童语音识别准确度高，$0.006/分钟 |
| 语音合成 (TTS) | OpenAI TTS | 自然语音输出 |
| 前端录音 | Web Audio API + MediaRecorder | 浏览器原生，无需插件 |

### 4.2 语音交互流程

```
孩子按住 [🎤] 按钮 → 开始录音
    ↓
松开按钮 → 停止录音 → 显示"精灵在听..."
    ↓
音频发送到 /api/voice/stt → Whisper API → 文字
    ↓
文字发送到 /api/ai/chat → GPT-4o → 流式文字回复
    ↓
同时：文字显示在对话气泡中 (流式)
    ↓
回复完成 → /api/voice/tts → 音频 → 自动播放
```

### 4.3 延迟预算

| 环节 | 预估延迟 | 用户感知 |
|------|---------|---------|
| 录音上传 + Whisper STT | 1-3s | 精灵显示"在听..." + 耳朵竖起动画 |
| GPT-4o 首 token | 0.5-1s | 精灵显示"在想..." + 思考动画 |
| GPT-4o 流式输出 | 持续 | 文字逐字出现在气泡中 |
| TTS 生成 | 1-2s | 文字显示完毕后自动播放语音 |
| **总计** | **3-6s** | 全程有动画反馈，不让孩子干等 |

## 5. 视觉设计规范

### 5.1 设计风格

吉卜力/治愈物语风格，温暖自然的视觉体验。AI 原生但不冰冷，保持手绘插画般的温暖感。

### 5.2 字体

```css
font-family: 'Open Sans', 'Noto Sans SC', sans-serif;
```

- **Open Sans**：西文字体，清晰友好
- **Noto Sans SC**：中文字体，Google 开源
- 超大标题使用 `font-weight: 900`

### 5.3 色彩体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#FDF6E3` | 吉卜力米白 |
| 主文字 | `#3A2E2C` | 深棕，温暖不刺眼 |
| 辅助文字 | `#5D4E4A` | 浅棕 |
| 说明文字 | `#8B7355` | 墨绿偏棕 |
| 强调色 | `#FFB300` | 琥珀黄，按钮和高亮 |
| 精灵气泡 | `#E8F5E9` | 浅绿，精灵对话背景 |
| 孩子气泡 | `#E3F2FD` | 浅蓝，孩子对话背景 |
| 成功色 | `#7CB342` | 柔绿 |
| 错误色 | `#E57373` | 柔红，不刺眼 |
| 卡片背景 | `rgba(255,255,255,0.75)` | 半透明白色 |

**禁忌**：不使用纯黑(#000)和纯白(#fff)，不用冷色调，不使用深色模式。

### 5.4 UI 组件规范

- **卡片**：`border-radius: 1.5rem` / `backdrop-filter: blur(12px)` / 半透明白背景
- **大触摸区域**：最小 44px（iPad 优化）
- **对话气泡**：`border-radius: 1rem` / 精灵靠左浅绿 / 孩子靠右浅蓝
- **选项按钮**：胶囊形 `border-radius: 9999px` / 强调色边框 / 大触摸目标
- **录音按钮**：圆形 64px / 按住时放大 + 脉冲动画 / 录音中红色指示

### 5.5 动效规范

| 场景 | 动效 | 时长 |
|------|------|------|
| 精灵出现 | 从底部弹入 + 轻微弹跳 | 0.5s ease-out |
| 对话气泡 | 从小到大 fade-in | 0.3s |
| 选项按钮 | 依次出现（stagger 0.1s） | 0.2s each |
| 种子种下 | 从手中落入土壤 + 尘土飞溅 | 0.8s |
| 种子发芽 | 慢慢冒出小苗 + 星光闪烁 | 1.5s |
| 花朵绽放 | 花苞展开 + 彩色粒子 | 2s |
| 精灵情绪 | 表情切换 + 轻微跳动 | 0.3s |
| 页面切换 | 水平滑动 + fade | 0.3s |

## 8. AI 错误处理矩阵

| 错误场景 | 检测方式 | 用户感知 | 降级策略 |
|---------|---------|---------|---------|
| OpenAI API 超时 (>10s) | 请求超时 | 精灵困惑表情 + "想太久了" | 提供重试按钮 + 预置话题选项 |
| OpenAI Rate Limit (429) | HTTP 状态码 | "精灵需要休息一下" | 指数退避重试，最多 3 次 |
| API Key 无效/余额不足 | HTTP 401/402 | "花园和外面断开了" | 通知家长端，显示离线活动 |
| 流式响应中断 | Stream error | 已显示的文字保留 + "说到一半断了" | 显示重试按钮 |
| 不当内容生成 | 内容过滤 | 不展示 + 精灵转移话题 | System prompt 安全规则 + 后端过滤 |
| Whisper STT 失败 | API error | "没听清，再说一次？" | 引导使用文字输入 |
| TTS 生成失败 | API error | 只显示文字，不播放语音 | 静默降级，不中断对话 |
| Token 上限 (上下文窗口) | Token 计数 | 无感知 | 自动截断早期对话，保留最近 N 条 |
| 网络断开 | navigator.onLine | "花园和外面断开了 🌧️" | 显示已缓存的花园和历史对话 |

## 10. 设计决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| 产品方向 | AI 原生教育平台 | 从"做题器"升级，AI 驱动的学习体验更能激发孩子主动性 |
| AI 提供商 | OpenAI 为主 | GPT-4o + Whisper + TTS 一站式，Vercel AI SDK 保留切换能力 |
| 语音方案 | Whisper API | 儿童语音识别准确度高，$1.8/月预算可控 |
| 孩子端策略 | 完全重写 | 从"做题 UI"转为"对话 + 花园 UI"，架构差异太大 |
| 家长端策略 | 渐进改造 | 保留现有结构，新增 AI 洞察面板 |
| 花园可视化 | Phase 2 加入基础版 | 花园是核心情感钩子，不应放到最后 |
| AI Prompt | 设计原则 + 示例 | 原则指导方向，示例提供参考，实现时持续迭代 |
| 交付节奏 | 详细规划，不设 deadline | 个人项目，按节奏推进 |
| 学习记录 | 纯个人追踪 | 不做排行榜/社交比较，关注个人成长 |
| 深色模式 | 不支持 | 儿童应用场景不需要 |
